    66→## 4. Dual-Mode Architecture (the one concept that explains everything)
    67→
    68→The console is built against a **`SystemAdapter` interface** with two implementations:
    69→
    70→| Mode | Adapter | Where it runs | Data plane |
    71→|---|---|---|---|
    72→| **Sandbox Mode** (development, now) | `SimulatedAdapter` | Inside this repo (Next API + mini-service) | `MockEngine` generates traffic, logs, events, statuses |
    73→| **Appliance Mode** (production, later) | `AgentAdapter` | Go agent on Debian appliance (port 8080) | Real nftables/Suricata/WireGuard/etc. |
    74→
    75→All UI and API code is written once against the adapter interface. Details:
    76→`docs/02-ARCHITECTURE/SIMULATION_LAYER.md`. This is ADR-004.

   184→## 7. API Contract (LOCKED)
   185→
   186→### 7.1 General rules
   187→
   188→- Base path: `/api/v1/…` (Next route handlers, NOT server actions).
   189→- Auth: httpOnly cookie `cryptsk_token` (JWT, 8h). API keys via `Authorization: Bearer ck_<key>` for machine access.
   190→- Response envelope: success `{ "data": …, "meta"?: … }`; error `{ "error": { "code", "message", "details"? } }`.
   191→- Standard errors: `VALIDATION_ERROR` 400, `UNAUTHORIZED` 401, `FORBIDDEN` 403, `NOT_FOUND` 404, `CONFLICT` 409, `RATE_LIMITED` 429, `INTERNAL` 500.
   192→- Pagination: `?page=1&limit=25&sort=-timestamp` → `meta: { page, limit, total, totalPages }`.
   193→- Filtering: `?q=` free text + field filters (`?severity=critical&since=ISO&until=ISO`).
   194→- All mutations write an `audit_log` row (actor, before/after) — enforced in `lib/api/handler.ts`.
   195→- Full standards: `docs/04-API/API_STANDARDS.md`. Full catalog with examples: `docs/04-API/ENDPOINTS.md`.

   315→### 7.3 Realtime events (socket.io, LOCKED)
   316→
   317→Transport: connect with `io("/?XTransformPort=3003")` — NEVER a port in the hostname.
   318→Service: `mini-services/realtime-service/` (bun --hot, port 3003).
   319→
   320→| Event (server → client) | Payload shape | Emitted |
   321→|---|---|---|
   322→| `metrics:tick` | `{ ts, ifaces: [{name, rxKbps, txKbps}], cpuPct, memPct, conntrackCount }` | every 2s |
   323→| `logs:tail` | `{ kind: "firewall"\|"ips", entry: FirewallLog \| IpsEvent }` | ~1–3/s, while tailed |
   324→| `alerts:new` | `{ notification: Notification }` | on generated threat/system alerts |
   325→| `sessions:update` | `{ kind: "vpn"\|"identity", diff: [...] }` | on session change |
   326→| `wan:status` | `{ iface, state: up\|down\|degraded }` | on probe state change |
   327→| `vpn:status` | `{ vpnId, status: up\|down\|connecting\|error, statusMessage? }` | on tunnel state change |
   328→| `config:updated` | `{ section: string }` | after any config mutation (clients refetch) |
   329→
   330→Client → server (subscribe control): `subscribe { channels: ["metrics","logs","alerts"] }`, `unsubscribe { channels }`.

   400→## 10. Database Rules (SQLite Adaptation — LOCKED)
   401→
   402→1. File DB at `db/cryptsk.db`; schema source = `prisma/schema.prisma`; apply with `bun run db:push`. Client: `import { db } from '@/lib/db'`.
   403→2. **PostgreSQL → SQLite mapping rules:**
   404→
   405→| Spec (PostgreSQL) | Build (Prisma/SQLite) |
   406→|---|---|
   407→| `SERIAL`/`BIGSERIAL` PK | `Int @id @default(autoincrement())` |
   408→| `TIMESTAMPTZ` | `DateTime` (stored ISO-8601 UTC) |
   409→| `JSONB` | `String` holding JSON (`@default("{}")` / `@default("[]")`), validated by zod, helpers in `lib/json.ts` |
   410→| `TEXT[]`, `INET[]`, `INTEGER[]` | `String` holding JSON array |
   411→| id-list references (`source_addr_ids INTEGER[]`) | `String` JSON array of ids = **logical reference**, integrity enforced in service layer |
   412→| `INET`, `CIDR`, `MACADDR` | `String` + zod validation (`ipv4()`, `cidr`, mac regex) |
   413→| `DATERANGE` | `startsAt DateTime?` + `endsAt DateTime?` |
   414→| PG enums | `String` + zod enum (§6 table) — **do NOT use Prisma enums on SQLite** |
   415→
   416→3. **No Prisma enums. No Prisma `Json` type. No array scalar types.** (Portability + SQLite guarantees.)
   417→4. Every tenant-scoped model has `tenantId Int @default(1)` FK → `tenants`. Sandbox seeds exactly one tenant (id 1, name "Default").
   418→5. Multi-row list endpoints paginate; big tables (`firewall_logs`, `ips_events`, `audit_log`) get `@@index` on `(tenantId, createdAt)` + hot filters.
   419→6. Definitive schema + per-model notes: `docs/03-DATABASE/SCHEMA.md`. Relations: `ER_DIAGRAM.md`. Seed/reset: `DATA_LIFECYCLE.md`.

   443→## 12. Recipes (How To Do Common Things)
   444→
   445→### Add a new view (client "page")
   446→1. Create `src/components/views/<module>/<View>.tsx`.
   447→2. Register in `src/components/shell/view-registry.ts` (hash path + component + nav meta).
   448→3. Add sidebar entry (auto from registry, grouped per §8).
   449→4. Add data hooks in `src/hooks/use-<resource>.ts` (TanStack Query, key `[resource, params]`).
   450→5. Respect: p-4/p-6, gap-4/6, max-h scroll lists, EmptyState, skeleton loading, 44px targets.
   451→
   452→### Add a new API resource
   453→1. Zod schemas in `src/lib/validators/<resource>.ts` (reuse §6 enums).
   454→2. Route handlers under `src/app/api/v1/<resource>/…` using `lib/api/handler.ts`
   455→   (envelope + auth + RBAC + audit are injected there — do not hand-roll).
   456→3. Adapter calls if runtime state is involved (`lib/adapters/`).
   457→4. Hooks + wire into views. Add/verify endpoint in `docs/04-API/ENDPOINTS.md`.
   458→
   459→### Add a DB table/column
   460→1. Edit `prisma/schema.prisma` (follow §10 rules; snake_case maps).
   461→2. `bun run db:push`.
   462→3. Update `docs/03-DATABASE/SCHEMA.md` + `ER_DIAGRAM.md` (+ seed if needed).
   463→4. Append session log entry.
   464→
   465→### Apply a config change (the core loop of a UTM)
   466→`UI → POST/PUT API → zod validate → DB write (tx) → audit_log → adapter.applyConfig(section)
   467→→ (sandbox: SimulatedAdapter marks version + broadcasts config:updated)
   468→→ (appliance: generator renders nftables.conf/unbound.conf/… → agent applies → status)`
   469→Sections: firewall | nat | interfaces | routing | dns | dhcp | vpn | ips | qos | ha | identity | system.
   470→Never let the UI talk to system services directly.
   471→
   472→### Debug something
   473→`bun run lint` → tail `dev.log` → browser check the exact hash view → check network tab
   474→for envelope shape. Do not add console.log spam; remove temp logs after.

   478→## 13. Gotchas (learned-the-hard-way section — keep appending)
   479→
   480→- Next 16 + React 19: keep `"use client"` on every interactive component; server components
   481→  cannot use zustand/socket hooks.
   482→- recharts + React 19: use the `ui/chart.tsx` shadcn wrapper patterns; avoid dynamic
   483→  imports inside render loops.
   484→- Prisma on SQLite: no enums/Json/arrays (see §10). Forgetting `@map` breaks snake_case contract.
   485→- TanStack Query: never inline `queryKey` objects without params; keys must include all
   486→  filters so cache invalidation works (`config:updated` handler invalidates by prefix).
   487→- socket.io through the gateway: query string must be exactly `?XTransformPort=3003`;
   488→  the mini-service must bind 0.0.0.0 and print its port at boot.
   489→- Mock data must be **seedable** (fixed seed) or screenshots/demos become unreproducible.
   490→- Time handling: store UTC, display with `date-fns` in user locale; the spec's schedules
   491→  use IANA timezone strings (`Asia/Calcutta` etc.).
   492→- Never render raw JSON blobs in UI without a `JsonFieldViewer` (monospace, collapsible).
   493→- Rate: logs tables must paginate server-side; loading 5k rows into a client table will jank.
