    12→    12→## 1. PostgreSQL → SQLite Mapping Rules (LOCKED, ADR-005)
    13→    13→
    14→    14→| Spec (PostgreSQL) | Prisma/SQLite here | Notes |
    15→    15→|---|---|---|
    16→    16→| `SERIAL` / `BIGSERIAL` PK | `Int @id @default(autoincrement())` | SQLite ints are 64-bit |
    17→    17→| `TIMESTAMPTZ` | `DateTime` | ISO-8601 UTC storage |
    18→    18→| `JSONB` | `String` (JSON text) `@default("{}")` / `@default("[]")` | zod-validated at the edges; helpers in `lib/json.ts` |
    19→    19→| `TEXT[]` / `INET[]` / `INTEGER[]` | `String` (JSON array text) | same as above |
    20→    20→| id lists (`source_addr_ids INTEGER[]`) | `String` JSON array of ids | **logical reference** — integrity enforced in service layer (see ER_DIAGRAM §3) |
    21→    21→| `INET` / `CIDR` / `MACADDR` | `String` + zod (`ipv4`, cidr regex, mac regex) | no DB-level type |
    22→    22→| `DATERANGE` | `startsAt DateTime?` + `endsAt DateTime?` | |
    23→    23→| PG enums | `String` + zod enum | **never Prisma enums, never Prisma Json, never array scalars on SQLite** |
    24→    24→| `VARCHAR(n)` | `String` | length enforced by zod |
    25→    25→
    26→    26→## 2. Conventions
    27→    27→
    28→    28→- Model name PascalCase singular; table/column snake_case via `@@map`/`@map`.
    29→    29→- Every tenant-scoped model: `tenantId Int @default(1)` + relation to `Tenant` (ADR-009).
    30→    30→- Timestamps: `createdAt DateTime @default(now())` → `created_at`; `updatedAt DateTime @updatedAt` → `updated_at` where the spec has it.
    31→    31→- Money/none. Big counters: `Int` (SQLite 64-bit is plenty for sandbox; appliance uses BIGINT equivalents).
    32→    32→- Deleting a parent with children: restrict for config objects (must reassign/clean children first); cascade only for `firewall_logs`/`ips_events` by retention job (never FK cascade on logs).

   774→   774→## 5. Index & Integrity Notes
   775→   775→
   776→   776→- Hot paths: `firewall_logs(tenantId,timestamp)`, `ips_events(tenantId,timestamp)`,
   777→   777→  `audit_log(tenantId,createdAt)`, `firewall_rules(tenantId,enabled,position)`.
   778→   778→- Log retention job (DATA_LIFECYCLE §4) deletes by timestamp in batches; no FK from logs to config tables (rows survive rule deletion — `ruleName`/`appName` are denormalized strings on purpose).
   779→   779→- Deletes: config objects RESTRICT when referenced (service layer checks logical refs before delete and returns `CONFLICT` with referencing rule names); children with FK cascade: reservations/leases (subnet), vpn_sessions (vpn), qos_rules (policy), group members.
   780→   780→- All list endpoints are tenant-scoped automatically (handler injects `tenantId` from JWT).
