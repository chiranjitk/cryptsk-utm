    70→## 4. Dual-Mode Architecture (the one concept that explains everything)
    71→
    72→The console is built against a **`SystemAdapter` interface** with two implementations:
    73→
    74→| Mode | Adapter | Where it runs | Data plane |
    75→|---|---|---|---|
    76→| **Sandbox Mode** (development, now) | `SimulatedAdapter` | Inside this repo (Next API + mini-service) | `MockEngine` generates traffic, logs, events, statuses |
    77→| **Appliance Mode** (production, later) | `AgentAdapter` | Go agent on Debian appliance (port 8080) | Real nftables/Suricata/WireGuard/etc. |
    78→
    79→All UI and API code is written once against the adapter interface. Details:
    80→`docs/02-ARCHITECTURE/SIMULATION_LAYER.md`. This is ADR-004.

   198→## 7. API Contract (LOCKED)
   199→
   200→### 7.1 General rules
   201→
   202→- Base path: `/api/v1/…` (Next route handlers, NOT server actions).
   203→- Auth: httpOnly cookie `cryptsk_token` (JWT, 8h). API keys via `Authorization: Bearer ck_<key>` for machine access.
   204→- Response envelope: success `{ "data": …, "meta"?: … }`; error `{ "error": { "code", "message", "details"?, "requestId"? } }` (`requestId` = per-request correlation id from the shared handler middleware — ADR-016).
   205→- Standard errors: `VALIDATION_ERROR` 400, `UNAUTHORIZED` 401, `FORBIDDEN` 403, `NOT_FOUND` 404, `CONFLICT` 409, `RATE_LIMITED` 429, `INTERNAL` 500.
   206→- Pagination: `?page=1&limit=25&sort=-timestamp` → `meta: { page, limit, total, totalPages }`.
   207→- Filtering: `?q=` free text + field filters (`?severity=critical&since=ISO&until=ISO`).
   208→- All mutations write an `audit_log` row (actor, before/after) — enforced in `lib/api/handler.ts`.
   209→- Full standards: `docs/04-API/API_STANDARDS.md`. Full catalog with examples: `docs/04-API/ENDPOINTS.md`.

   458→## 10. Database Rules (SQLite Adaptation — LOCKED)
   459→
   460→1. File DB at `db/cryptsk.db`; schema source = `prisma/schema.prisma`; apply with `bun run db:push`. Client: `import { db } from '@/lib/db'`.
   461→2. **PostgreSQL → SQLite mapping rules:**
   462→
   463→| Spec (PostgreSQL) | Build (Prisma/SQLite) |
   464→|---|---|
   465→| `SERIAL`/`BIGSERIAL` PK | `Int @id @default(autoincrement())` |
   466→| `TIMESTAMPTZ` | `DateTime` (stored ISO-8601 UTC) |
   467→| `JSONB` | `String` holding JSON (`@default("{}")` / `@default("[]")`), validated by zod, helpers in `lib/json.ts` |
   468→| `TEXT[]`, `INET[]`, `INTEGER[]` | `String` holding JSON array |
   469→| id-list references (`source_addr_ids INTEGER[]`) | `String` JSON array of ids = **logical reference**, integrity enforced in service layer |
   470→| `INET`, `CIDR`, `MACADDR` | `String` + zod validation (`ipv4()`, `cidr`, mac regex) |
   471→| `DATERANGE` | `startsAt DateTime?` + `endsAt DateTime?` |
   472→| PG enums | `String` + zod enum (§6 table) — **do NOT use Prisma enums on SQLite** |
   473→
   474→3. **No Prisma enums. No Prisma `Json` type. No array scalar types.** (Portability + SQLite guarantees.)
   475→4. Every tenant-scoped model has `tenantId Int @default(1)` FK → `tenants`. Sandbox seeds exactly one tenant (id 1, name "Default").
   476→5. Multi-row list endpoints paginate; big tables (`firewall_logs`, `ips_events`, `audit_log`) get `@@index` on `(tenantId, createdAt)` + hot filters.
   477→6. Definitive schema + per-model notes: `docs/03-DATABASE/SCHEMA.md`. Relations: `ER_DIAGRAM.md`. Seed/reset: `DATA_LIFECYCLE.md`.

   536→## 13. Gotchas (learned-the-hard-way section — keep appending)
   537→
   538→- Next 16 + React 19: keep `"use client"` on every interactive component; server components
   539→  cannot use zustand/socket hooks.
   540→- recharts + React 19: use the `ui/chart.tsx` shadcn wrapper patterns; avoid dynamic
   541→  imports inside render loops.
   542→- Prisma on SQLite: no enums/Json/arrays (see §10). Forgetting `@map` breaks snake_case contract.
   543→- TanStack Query: never inline `queryKey` objects without params; keys must include all
   544→  filters so cache invalidation works (`config:updated` handler invalidates by prefix).
   545→- socket.io through the gateway: query string must be exactly `?XTransformPort=3003`;
   546→  the mini-service must bind 0.0.0.0 and print its port at boot.
   547→- Mock data must be **seedable** (fixed seed) or screenshots/demos become unreproducible.
   548→- Time handling: store UTC, display with `date-fns` in user locale; the spec's schedules
   549→  use IANA timezone strings (`Asia/Calcutta` etc.).
   550→- Never render raw JSON blobs in UI without a `JsonFieldViewer` (monospace, collapsible).
   551→- Rate: logs tables must paginate server-side; loading 5k rows into a client table will jank.
