    66→## 4. Dual-Mode Architecture (the one concept that explains everything)
    67→
    68→The console is built against a **`SystemAdapter` interface** with two implementations:
    69→
    70→| Mode | Adapter | Where it runs | Data plane |
    71→|---|---|---|---|
    72→| **Sandbox Mode** (development, now) | `SimulatedAdapter` | Inside this repo (Next API + mini-service) | `MockEngine` generates traffic, logs, events, statuses |
    73→| **Appliance Mode** (production, later) | `AgentAdapter` | Go agent on Debian appliance (port 8080) | Real nftables/Suricata/WireGuard/etc. |
    74→
    75→All UI and API code is written once against the adapter interface. Details:
    76→`docs/02-ARCHITECTURE/SIMULATION_LAYER.md`. This is ADR-004.

   183→## 7. API Contract (LOCKED)
   184→
   185→### 7.1 General rules
   186→
   187→- Base path: `/api/v1/…` (Next route handlers, NOT server actions).
   188→- Auth: httpOnly cookie `cryptsk_token` (JWT, 8h). API keys via `Authorization: Bearer ck_<key>` for machine access.
   189→- Response envelope: success `{ "data": …, "meta"?: … }`; error `{ "error": { "code", "message", "details"?, "requestId"? } }` (`requestId` = per-request correlation id from the shared handler middleware — ADR-016).
   190→- Standard errors: `VALIDATION_ERROR` 400, `UNAUTHORIZED` 401, `FORBIDDEN` 403, `NOT_FOUND` 404, `CONFLICT` 409, `RATE_LIMITED` 429, `INTERNAL` 500.
   191→- Pagination: `?page=1&limit=25&sort=-timestamp` → `meta: { page, limit, total, totalPages }`.
   192→- Filtering: `?q=` free text + field filters (`?severity=critical&since=ISO&until=ISO`).
   193→- All mutations write an `audit_log` row (actor, before/after) — enforced in `lib/api/handler.ts`.
   194→- Full standards: `docs/04-API/API_STANDARDS.md`. Full catalog with examples: `docs/04-API/ENDPOINTS.md`.

   314→### 7.3 Realtime events (socket.io, LOCKED)
   315→
   316→Transport: connect with `io("/?XTransformPort=3003")` — NEVER a port in the hostname.
   317→Service: `mini-services/realtime-service/` (bun --hot, port 3003).
   318→
   319→| Event (server → client) | Payload shape | Emitted |
   320→|---|---|---|
   321→| `metrics:tick` | `{ ts, ifaces: [{name, rxKbps, txKbps}], cpuPct, memPct, conntrackCount }` | every 2s |
   322→| `logs:tail` | `{ kind: "firewall"\|"ips", entry: FirewallLog \| IpsEvent }` | ~1–3/s, while tailed |
   323→| `alerts:new` | `{ notification: Notification }` | on generated threat/system alerts |
   324→| `sessions:update` | `{ kind: "vpn"\|"identity", diff: [...] }` | on session change |
   325→| `wan:status` | `{ iface, state: up\|down\|degraded }` | on probe state change |
   326→| `vpn:status` | `{ vpnId, status: up\|down\|connecting\|error, statusMessage? }` | on tunnel state change |
   327→| `config:updated` | `{ section: string }` | after any config mutation (clients refetch) |
   328→
   329→Client → server (subscribe control): `subscribe { channels: ["metrics","logs","alerts"] }`, `unsubscribe { channels }`.

   399→## 10. Database Rules (SQLite Adaptation — LOCKED)
   400→
   401→1. File DB at `db/cryptsk.db`; schema source = `prisma/schema.prisma`; apply with `bun run db:push`. Client: `import { db } from '@/lib/db'`.
   402→2. **PostgreSQL → SQLite mapping rules:**
   403→
   404→| Spec (PostgreSQL) | Build (Prisma/SQLite) |
   405→|---|---|
   406→| `SERIAL`/`BIGSERIAL` PK | `Int @id @default(autoincrement())` |
   407→| `TIMESTAMPTZ` | `DateTime` (stored ISO-8601 UTC) |
   408→| `JSONB` | `String` holding JSON (`@default("{}")` / `@default("[]")`), validated by zod, helpers in `lib/json.ts` |
   409→| `TEXT[]`, `INET[]`, `INTEGER[]` | `String` holding JSON array |
   410→| id-list references (`source_addr_ids INTEGER[]`) | `String` JSON array of ids = **logical reference**, integrity enforced in service layer |
   411→| `INET`, `CIDR`, `MACADDR` | `String` + zod validation (`ipv4()`, `cidr`, mac regex) |
   412→| `DATERANGE` | `startsAt DateTime?` + `endsAt DateTime?` |
   413→| PG enums | `String` + zod enum (§6 table) — **do NOT use Prisma enums on SQLite** |
   414→
   415→3. **No Prisma enums. No Prisma `Json` type. No array scalar types.** (Portability + SQLite guarantees.)
   416→4. Every tenant-scoped model has `tenantId Int @default(1)` FK → `tenants`. Sandbox seeds exactly one tenant (id 1, name "Default").
   417→5. Multi-row list endpoints paginate; big tables (`firewall_logs`, `ips_events`, `audit_log`) get `@@index` on `(tenantId, createdAt)` + hot filters.
   418→6. Definitive schema + per-model notes: `docs/03-DATABASE/SCHEMA.md`. Relations: `ER_DIAGRAM.md`. Seed/reset: `DATA_LIFECYCLE.md`.

   442→## 12. Recipes (How To Do Common Things)
   443→
   444→### Add a new view (client "page")
   445→1. Create `src/components/views/<module>/<View>.tsx`.
   446→2. Register in `src/components/shell/view-registry.ts` (hash path + component + nav meta).
   447→3. Add sidebar entry (auto from registry, grouped per §8).
   448→4. Add data hooks in `src/hooks/use-<resource>.ts` (TanStack Query, key `[resource, params]`).
   449→5. Respect: p-4/p-6, gap-4/6, max-h scroll lists, EmptyState, skeleton loading, 44px targets.
   450→
   451→### Add a new API resource
   452→1. Zod schemas in `src/lib/validators/<resource>.ts` (reuse §6 enums).
   453→2. Route handlers under `src/app/api/v1/<resource>/…` using `lib/api/handler.ts`
   454→   (envelope + auth + RBAC + audit are injected there — do not hand-roll).
   455→3. Adapter calls if runtime state is involved (`lib/adapters/`).
   456→4. Hooks + wire into views. Add/verify endpoint in `docs/04-API/ENDPOINTS.md`.
   457→
   458→### Add a DB table/column
   459→1. Edit `prisma/schema.prisma` (follow §10 rules; snake_case maps).
   460→2. `bun run db:push`.
   461→3. Update `docs/03-DATABASE/SCHEMA.md` + `ER_DIAGRAM.md` (+ seed if needed).
   462→4. Append session log entry.
   463→
   464→### Apply a config change (the core loop of a UTM)
   465→`UI → POST/PUT API → zod validate → DB write (tx) → audit_log → adapter.applyConfig(section)
   466→→ (sandbox: SimulatedAdapter marks version + broadcasts config:updated)
   467→→ (appliance: generator renders nftables.conf/unbound.conf/… → agent applies → status)`
   468→Sections: firewall | nat | interfaces | routing | dns | dhcp | vpn | ips | qos | ha | identity | system.
   469→Never let the UI talk to system services directly.
   470→
   471→### Debug something
   472→`bun run lint` → tail `dev.log` → browser check the exact hash view → check network tab
   473→for envelope shape. Do not add console.log spam; remove temp logs after.

   477→## 13. Gotchas (learned-the-hard-way section — keep appending)
   478→
   479→- Next 16 + React 19: keep `"use client"` on every interactive component; server components
   480→  cannot use zustand/socket hooks.
   481→- recharts + React 19: use the `ui/chart.tsx` shadcn wrapper patterns; avoid dynamic
   482→  imports inside render loops.
   483→- Prisma on SQLite: no enums/Json/arrays (see §10). Forgetting `@map` breaks snake_case contract.
   484→- TanStack Query: never inline `queryKey` objects without params; keys must include all
   485→  filters so cache invalidation works (`config:updated` handler invalidates by prefix).
   486→- socket.io through the gateway: query string must be exactly `?XTransformPort=3003`;
   487→  the mini-service must bind 0.0.0.0 and print its port at boot.
   488→- Mock data must be **seedable** (fixed seed) or screenshots/demos become unreproducible.
   489→- Time handling: store UTC, display with `date-fns` in user locale; the spec's schedules
   490→  use IANA timezone strings (`Asia/Calcutta` etc.).
   491→- Never render raw JSON blobs in UI without a `JsonFieldViewer` (monospace, collapsible).
   492→- Rate: logs tables must paginate server-side; loading 5k rows into a client table will jank.
